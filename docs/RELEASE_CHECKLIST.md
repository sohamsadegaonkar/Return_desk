Everything is initially unchecked. This is a future gate, not a release declaration.
- [ ] Required stack and original implementation verified.
- [ ] All five business rules pass direct HTTP tests.
- [ ] PostgreSQL restart persistence, migration and safe seed verified.
- [ ] 36 visible seeded requests and required variety.
- [ ] Combined SQL search/filter/sort/paging and no browser-only filtering.
- [ ] 375px UI, legal actions and loading/empty/error recovery verified.
- [ ] Applicable tests, build/type/lint checks pass on submitted revision.
- [ ] Exact candidate reviewed before push; remote SHA and CI checked.
- [ ] Checkpoints, research log, decisions, STATUS and NEXT_STEP current.
- [ ] User acknowledgment recorded accurately, without invented approvals.
- [ ] Public deployed app usable with attached DB; external smoke check.
- [ ] Public GitHub source and deployed URL in README and repo description.
- [ ] README clean setup, env example, migrations, seed, assumptions, incomplete work and actual hours truthful.
- [ ] No secrets, private assignment email or sensitive evidence published.
- [ ] Genuine incremental commits and ability to explain code/design alternatives.
- [ ] Submit the two links before actual email deadline; no ZIP.

Email sending is a separate person-directed action requiring explicit authorization. Preparing this checklist does not send anything.
