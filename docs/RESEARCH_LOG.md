## R-014 — 23 October 2026: opt-in public smoke and offline CI isolation
Freshly reviewed [Node.js native test runner documentation](https://nodejs.org/download/release/latest-jod/docs/api/test.html) for `node --test` with injected transport, and [GitHub secure workflow guidance](https://docs.github.com/en/actions/reference/security/secure-use) for least-privilege routine PR CI. Live write tests must **not** run from unauthenticated `pull_request` events against a public endpoint, even without secrets: they create persistent records and are susceptible to misuse. The safer design is offline test coverage in `.github/workflows/verify.yml` and a manual, explicit `RETURNDESK_LIVE_TEST=YES` guard for public writes from a trusted operator. Target URL is fixed (no arbitrary-host override), writes use synthetic `example.test` addresses, no credential is needed/printed. The test is an operational smoke and not a new scientific performance claim; no relevant new research paper applies.
